# Activity 10 · IPL Ticket Booking

Open a terminal in this folder, run `npm install`, then run `npm run dev`. Open the Local URL printed by Vite. Use `npm run build` for the production build.

Navbar and Hero render the header and banner. App maps over the sample fixtures in src/matches.js and passes each match to MatchCard as a prop. Selecting a card updates selectedId in App and displays the chosen teams below the schedule.
